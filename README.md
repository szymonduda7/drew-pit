# DREW-PIT

Strona wizytówka producenta mebli na wymiar z Weryni koło Kolbuszowej (index.html + uslugi.html).

- `index.html`: hero z kolażem trzech zdjęć realizacji, usługi, argumenty, darmowa wycena, galeria realizacji z lightboxem, ocena z Facebooka, kontakt z mapą i godzinami
- `uslugi.html`: karty usług (kuchnie, przedpokoje, szafy i garderoby, RTV i pokojowe, lokale i biura, pomiar i montaż)
- `styles.css`, `main.js`: wspólne style i skrypty
- `images/*.webp`: zdjęcia realizacji

Tailwind CSS i ikony Lucide z CDN, fonty Familjen Grotesk + Instrument Sans.
